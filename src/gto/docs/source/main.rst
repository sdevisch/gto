Main Module
==========

.. automodule:: main
   :members:
   :undoc-members:
   :show-inheritance:

The main module provides the core functionality of the GTO Data Change Detection system. It includes:

* Data change monitoring
* Documentation generation
* System demonstration

Example Usage
------------

.. code-block:: python

   from main import demonstrate_functionality
   
   # Run the demonstration
   demonstrate_functionality()
   
   # Generate documentation
   generate_documentation()
